# 证券交收失败监控 E2E Demo 材料包

这是一套完全构造、可公开演示的原始材料，用来验证 Ontology Studio 能否在不依赖 ADT 或 Cash Trading 预置内容的情况下，从空白 Solution 构建待人工复核的 Ontology Package。

## 演示时上传的四个物理文件

| 文件 | 在产品中选择的用途 | 说明 |
|---|---|---|
| `01_业务需求与流程.md` | 需求文档（转写） | 业务范围、角色、端到端过程、七条分析问题和期望输出 |
| `02_指标逻辑.md` | 指标逻辑（转写） | 七项指标的口径、公式、粒度、维度、缺失和零分母规则 |
| `03_数据模型_数据字典_样例数据.xlsx` | 数据模型；数据字典（同一文件勾选两种用途） | 表、字段、关系、枚举和构造型样例数据 |
| `04_现有计算逻辑.sql` | 现有 SQL | PostgreSQL 参考计算逻辑 |

`source-manifest.json` 是自动验收脚本使用的登记清单，不需要在 UI 演示中上传。

## 自洽基准

统计日 `2026-08-20` 的预期结果：

- 到期指令数：7
- 活跃失败数：4
- 失败率：57.1429%
- 活跃失败未交收金额：HKD 124,000
- 平均失败年龄：1.50 个营业日
- 两个营业日内恢复率：20.00%
- 前三参与者失败金额集中度：87.9032%

材料中的业务口径、样例数据和 SQL 均应得到上述结果。
