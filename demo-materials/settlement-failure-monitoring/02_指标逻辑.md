# 证券交收失败监控：指标逻辑

## 1. 通用计算上下文

| 项目 | 统一口径 |
|---|---|
| 默认统计日 | 用户指定的 `snapshot_date` |
| 每日统计截点 | 18:30 HKT |
| 当前快照粒度 | `snapshot_date + instruction_id` 唯一一行 |
| 目标市场 | `EXCHANGE_TRADED_EQUITY` |
| 排除状态 | `CANCELLED` |
| 金额报告币种 | HKD |
| 缺失值原则 | 不以 0 替代未知值；形成数据质量缺口 |
| 比率聚合原则 | 先汇总分子与分母，再做除法；禁止直接平均行级百分比 |
| 零分母原则 | 返回 `N/A`，同时显示分子 0、分母 0 |
| 失败年龄原则 | 首次失败日为第 0 天，只累计之后经过的香港营业日 |

## 2. 指标目录

### M-01 到期交收指令数

| 属性 | 定义 |
|---|---|
| 业务名称 | 到期交收指令数 |
| 技术 ID | `metric.due_instruction_count` |
| 业务含义 | 在统计日已经到期、属于目标市场且未取消的交收指令数量 |
| 公式 | `COUNT(DISTINCT instruction_id)` |
| 过滤条件 | `market_type = 'EXCHANGE_TRADED_EQUITY' AND settlement_date <= snapshot_date AND status <> 'CANCELLED'` |
| 粒度 | 统计日 |
| 单位 | 条 |
| 允许维度 | 参与者、证券、交收币种、状态 |
| 数据来源 | `settlement_instruction_snapshot` |

### M-02 活跃交收失败数

| 属性 | 定义 |
|---|---|
| 业务名称 | 活跃交收失败数 |
| 技术 ID | `metric.active_fail_count` |
| 业务含义 | 到期但在统计截点仍有剩余数量且尚未完成交收的指令数量 |
| 公式 | `COUNT(DISTINCT instruction_id)` |
| 过滤条件 | M-01 资格条件，且 `remaining_quantity > 0 AND status IN ('PENDING','PARTIALLY_SETTLED','FAILED')` |
| 粒度 | 统计日 |
| 单位 | 条 |
| 允许维度 | 参与者、证券、交收币种、失败原因、状态 |
| 数据来源 | `settlement_instruction_snapshot` |

### M-03 交收失败率

| 属性 | 定义 |
|---|---|
| 业务名称 | 交收失败率 |
| 技术 ID | `metric.settlement_fail_rate` |
| 业务含义 | 到期指令中在统计截点仍处于活跃失败的比例 |
| 公式 | `M-02 / M-01` |
| 聚合方式 | 比率的分子和分母分别求和后再相除 |
| 零分母 | M-01 为 0 时返回 `N/A` |
| 粒度 | 统计日 |
| 单位 | 百分比 |
| 允许维度 | 参与者、证券、交收币种 |
| 数据来源 | M-01、M-02 |

### M-04 活跃失败未交收金额（HKD）

| 属性 | 定义 |
|---|---|
| 业务名称 | 活跃失败未交收金额（HKD） |
| 技术 ID | `metric.active_fail_outstanding_hkd` |
| 业务含义 | 活跃失败指令剩余数量按统计日参考价格和汇率折算的港币金额 |
| 行级公式 | `remaining_quantity × close_price × hkd_rate` |
| 汇总公式 | 对有效行级金额求和 |
| 过滤条件 | M-02 资格条件；价格和汇率均存在 |
| 缺失处理 | 缺少价格或汇率的记录不计入金额，并输出缺口数量和指令 ID |
| 粒度 | 指令×统计日，向上汇总 |
| 单位 | HKD |
| 允许维度 | 参与者、证券、交收币种、失败原因 |
| 数据来源 | `settlement_instruction_snapshot`、`daily_price`、`fx_rate` |

### M-05 活跃失败平均年龄（营业日）

| 属性 | 定义 |
|---|---|
| 业务名称 | 活跃失败平均年龄（营业日） |
| 技术 ID | `metric.average_active_fail_age_bd` |
| 业务含义 | 当前活跃失败从首次失败日到统计日经历的平均香港营业日数 |
| 行级公式 | `COUNT(calendar_date WHERE first_failed_date < calendar_date <= snapshot_date AND is_business_day = true)` |
| 汇总公式 | `AVG(fail_age_business_days)` |
| 过滤条件 | M-02 资格条件且 `first_failed_date IS NOT NULL` |
| 缺失处理 | 首次失败日为空的活跃失败不进入平均值，并形成缺口 |
| 粒度 | 指令×统计日，向上汇总 |
| 单位 | 营业日 |
| 允许维度 | 参与者、证券、失败原因、年龄区间 |
| 数据来源 | `settlement_instruction_snapshot`、`trading_calendar` |

### M-06 两个营业日内恢复率

| 属性 | 定义 |
|---|---|
| 业务名称 | 两个营业日内恢复率 |
| 技术 ID | `metric.recovery_within_2bd_rate` |
| 业务含义 | 曾经失败的到期指令中，在首次失败后两个香港营业日内完成交收的比例 |
| 分母 | `first_failed_date IS NOT NULL` 的到期指令数 |
| 分子 | 分母中 `fully_settled_date IS NOT NULL` 且恢复营业日数 `<= 2` 的指令数 |
| 公式 | `recovered_within_2bd_count / failed_cohort_count` |
| 零分母 | 失败队列数为 0 时返回 `N/A` |
| 队列归属 | 以 `first_failed_date` 作为 cohort date |
| 粒度 | 首次失败日队列 |
| 单位 | 百分比 |
| 允许维度 | 参与者、证券、失败原因 |
| 数据来源 | `settlement_instruction_snapshot`、`trading_calendar` |

### M-07 前三参与者失败金额集中度

| 属性 | 定义 |
|---|---|
| 业务名称 | 前三参与者失败金额集中度 |
| 技术 ID | `metric.top3_participant_fail_amount_share` |
| 业务含义 | 按活跃失败港币金额排名前三的参与者占全部有效失败金额的比例 |
| 分子 | 参与者维度 M-04 排名前三的金额之和 |
| 分母 | 全部参与者的 M-04 |
| 公式 | `SUM(top 3 participant M-04) / SUM(all participant M-04)` |
| 零分母 | 全部有效失败金额为 0 时返回 `N/A` |
| 粒度 | 统计日 |
| 单位 | 百分比 |
| 允许维度 | 参与者类型、交收币种 |
| 数据来源 | M-04、`participant_reference` |

## 3. 指标间依赖

| 上游指标/规则 | 下游指标 |
|---|---|
| 到期指令资格规则 | M-01、M-02、M-03、M-06 |
| 活跃失败资格规则 | M-02、M-03、M-04、M-05、M-07 |
| `M-01` | `M-03` |
| `M-02` | `M-03` |
| `M-04` | `M-07` |
| 香港营业日规则 | M-05、M-06 |
