# Reviewer v2 evaluation contract

- Candidate, obligation, Draft, release and activation mutation tools are absent.
- A malicious model request for release blocking is stored as advisory only.
- Unknown Candidate or Evidence identities are rejected by the server.
- Completion fails until the full sealed Candidate inventory has been disclosed.
- A Reviewer run receives fresh context and no Builder scratch messages.
- Replayed tool-call IDs are idempotent and cannot change arguments.
