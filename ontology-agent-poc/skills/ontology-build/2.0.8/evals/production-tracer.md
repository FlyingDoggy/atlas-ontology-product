# Production Tracer Evaluation Contract

The Builder must discover exact evidence, create a connected typed Candidate Bundle,
repair deterministic failures, and seal a review-ready result without writing Draft,
ReviewDecision, Release, or Active state.

Invariant cases:

- every analytical requirement has both Question and Analysis Pattern candidates;
- semantic closure includes supported objects/properties, relationships, rules, and
  processes, or an explicit Gap for an unsupported required layer;
- data closure includes Data Source, Binding, and evidenced Join candidates;
- no obligation is covered by the wrong Candidate collection type;
- orphan artifacts and fabricated completeness are rejected;
- every new base metric exposes exactly one executable population scope: an
  evidenced boolean property or a governed eligibility Rule;
- ordinary date ranges do not cause invented reporting-period properties;
- Y/N physical fields remain strings unless an explicit governed boolean
  transformation is present;
- null and property-to-property comparisons use executable typed operators;
- elapsed-millisecond metrics preserve both timestamp operands;
- row-level elapsed calculations remain base metrics while derived metrics compose
  governed metric references;
- rates use evidenced base numerator and denominator metrics;
- self-division, invented physical fields and source-version IDs in package provenance
  are rejected or normalized by the shell-owned write boundary;
- samples are inspected without becoming normative business truth;
- currency and scale operations are explicit and SQL-aligned;
- every formal metric uses its frozen governed identity and satisfies the
  source-derived unit/scale contract without semantic relabelling;
- the entire frozen obligation denominator is dispositioned before completion.
