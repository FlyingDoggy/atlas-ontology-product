# ADT reference intake

本目录模拟 External Review Team 在不能带出 customer 原始材料时可提供的安全输入。

- `requirements_and_process.md`：由团队人工转写的需求、业务过程、分析流程和期望答案。
- `metric_logic.md`：由团队人工转写的指标定义、口径、边界和待确认项。
- `data_model.md`：本参考场景直接提供的合成数据模型附件。
- `data_dictionary.csv`：本参考场景直接提供的字段字典；实际项目可以是 Excel、CSV 或文档。
- `../sql/existing_adt.sql`：现有计算 SQL 样例；实际项目直接交文件，不需要抄进模板。

这些材料都不代表 customer 的真实定义。它们只用于验证从有限的人工作业输入到可发布 ontology snapshot 的方法。
